# 🎬 VidFlow | Node.js, Vite e Consumo de API

Projeto desenvolvido durante meus estudos na **Alura**, com o objetivo de aprofundar meus conhecimentos em JavaScript, Node.js, ferramentas de desenvolvimento e consumo de APIs.

O VidFlow é uma aplicação web inspirada em plataformas de vídeos, que permite visualizar conteúdos carregados dinamicamente a partir de uma API.

## 🚀 Tecnologias utilizadas

- **HTML5** — Estruturação da interface.
- **CSS3** — Estilização e responsividade.
- **JavaScript** — Lógica e manipulação do DOM.
- **Node.js e npm** — Ambiente de desenvolvimento e gerenciamento de dependências.
- **Vite** — Servidor de desenvolvimento e ferramenta de build.
- **Axios** — Requisições HTTP para consumir os dados.
- **JSON Server** — Simulação de uma API REST para fornecer os vídeos.

## 💻 Funcionalidades

- Interface responsiva inspirada em plataformas de vídeos.
- Carregamento dinâmico de vídeos.
- Consumo de uma API REST local.
- Renderização de conteúdos utilizando JavaScript.
- Separação entre interface e fornecimento de dados.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pude praticar:

- Configuração do ambiente de desenvolvimento com Node.js.
- Gerenciamento de pacotes utilizando npm.

## ⚙️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/Guilherme-code10/nodejs-vidflow-vite.git
```

**2. Acesse a pasta:**

```bash
cd nodejs-vidflow-vite
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o frontend:**

```bash
npm run dev
```

**5. Em outro terminal, inicie a API:**

```bash
npm run api-local
```

Acesse o endereço informado pelo Vite, normalmente `http://localhost:5173/`.

A API local estará disponível em `http://localhost:3000/videos`, caso a porta padrão esteja livre.
